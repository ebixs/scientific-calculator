# 🧮 Scientific Calculator

A clean, dependency-free scientific calculator built with vanilla HTML, CSS, and JavaScript. Focuses on state management and UI fundamentals.

## 🚀 Live Demo
👉 **[Open Scientific Calculator](https://ebixs.github.io/scientific-calculator/)**

## Key Features
- **Operations:** Basic (+, -, *, /) and Scientific (√, x², xʸ, 1/x, %).
- **State Engine:** Handles operation chaining and running totals.
- **Keyboard Support:** Full mapping for fast input (digits, operators, Enter, Backspace, Esc).
- **Responsive:** Fluid layout designed for both desktop and mobile screens.
- **Vanilla Tech:** Zero dependencies, high performance, and accessible.

## Project Structure
- `index.html`: Semantic markup and structure.
- `style.css`: Grid-based layout with custom properties (CSS variables).
- `script.js`: State-machine implementation for calculation logic.
